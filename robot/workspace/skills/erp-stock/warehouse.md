# 仓库查询

工具：`get_warehouse_info`

按关键词查启用中的门店仓和企业仓库。库存或盘点查询要用的「仓库ID」从这里拿。

名称里出现「物资」的仓库默认不用。物资仓放的是门店物料，例如塑料袋、气球、本子等日常消耗品。只有用户点名要查物资仓、物资仓库时，才选用这类仓库，并把它的「仓库ID」传给后续工具。查总部盘点时优先选「仓库类型」为「企业仓库」、名称常带「仓」字的记录，细则见 `/skills/erp-stock/inventory_audit.md`。

## 参数

| 参数 | 含义 | 默认 | 取值 |
| --- | --- | --- | --- |
| `keyword` | 模糊查询 | 必填 | 门店名称、门店简称、门店编码、助记码 |
| `current` | 页码 | `1` | 正整数 |
| `size` | 每页条数 | `10` | 正整数 |

`keyword` 支持模糊匹配，下面四种都可以直接传：

- 门店名称，如「四川康惠多大药房连锁有限公司五星路店」
- 门店简称，如「五星路店」
- 门店编码
- 助记码：名称每个字的拼音首字母，并且是大写。例如「六味地黄丸」的助记码是 `LWDHW`

用户只说了一个短名时，把短名原样放进 `keyword`，不要先改写成全称。

用户给的是一串大写字母或小写字母（如 `AMXL`、`amxl`）时，把它当作助记码（小写需转换成大写），原样传给 `keyword`。不要把字母展开成中文名称，也不要改成小写。例如「查一下 AMXL 的信息」直接查 `keyword="AMXL"`。

## 调用流程

1. 从用户话里抽出门店名称、简称、编码或助记码，作为 `keyword`
2. 调用 `get_warehouse_info`
3. 看 `status`、`data`、`page_info`
4. 从候选里去掉「仓库名称」含「物资」的记录。用户点名要查物资仓时保留，并只用这些记录
5. 后续要查库存时，记下留下的那条的「租户ID」和「仓库ID」

`page_info.pages` 大于 `page_info.current` 时，还有下一页。用户要完整清单就增大 `current` 继续查；只是定位一家门店时，先在当前页里找最匹配的一条。

## 返回结构

成功：`status` 为 `success`。列表在 `data`，分页在 `page_info`（`current` / `size` / `pages` / `total`）。

无数据：`status` 为 `error`，`message` 为「未找到店铺信息」。这表示当前关键词没有命中仓库，换一个名称、简称或编码再查。

未授权：`message` 为「未授权」。直接告诉用户未授权，不要换关键词、翻页或改参数再试。

`data` 每条记录包含下面全部字段，顺序与 `warehouse_information_data_process` 的输出一致：

| 字段 | 用途 |
| --- | --- |
| `租户ID` | 传给 `get_inventory_data` 或 `get_inventory_audit_summary_data` 的 `tenant_id` |
| `企业ID` | 企业标识，展示或核对时使用 |
| `企业名称` | 仓库所属企业 |
| `门店/仓库编码` | 展示，和用户给的编码核对 |
| `门店/仓库名称` | 展示 |
| `门店/仓库简称` | 展示；用户口头说的短名通常对这个字段 |
| `仓库ID` | 传给 `get_inventory_data` 或 `get_inventory_audit_summary_data` 的 `warehouse_id`。名称含「物资」的默认不传 |
| `仓库名称` | 展示 |
| `区域名称` | 展示 |
| `仓库类型` | `门店仓`（原值 `sto`）或 `企业仓库`（原值 `dc`） |
| `座机号码` | 仅用户问电话时展示 |
| `仓库地址` | 仅用户问地址时展示 |

用户问的是门店库存时，用「仓库类型」为「门店仓」的记录。同名下还有「企业仓库」时，先说明两者都有，默认按门店仓继续，除非用户明确要企业仓库。企业仓库里名称含「物资」的，仍按上面的规则默认忽略。

去掉物资仓后仍有多家、且无法唯一对应时，列出名称、简称、仓库 ID、仓库类型，请用户选一条。不要自己挑一个继续查库存。候选全是物资仓、而用户没点名要查时，告诉用户这些是物资仓，默认不查，并问要不要查。

## 示例

用户：「五星路店的仓库」

```
get_warehouse_info(keyword="五星路店")
```

用户给了门店编码 `1001`：

```
get_warehouse_info(keyword="1001")
```

用户：「查一下 AMXL 的信息」

```
get_warehouse_info(keyword="AMXL")
```
