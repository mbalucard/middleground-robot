# 门店查询

工具：`get_shop_available_info`

查正常营业的门店。零售查询要用的「门店编码」从这里拿。

这个工具只查状态为正常的门店。停用门店不在结果里。用户要查停用门店时，直接说明当前只能查正常门店。

## 参数

| 参数 | 含义 | 默认 | 取值 |
| --- | --- | --- | --- |
| `keyword` | 模糊查询 | 必填 | 门店名称、门店简称、门店编码、助记码 |
| `current` | 页码 | `1` | 正整数 |
| `size` | 每页条数 | `10` | 正整数。保持 `10` |
| `tenant_id` | 租户 ID | 无 | 已知租户时传整数。不确定时不传 |

`keyword` 必填。没有名称、简称、编码或助记码时，不要调用，请用户补充。

`keyword` 支持模糊匹配，下面四种都可以直接传：

- 门店名称，如「四川康惠多大药房连锁有限公司五星路店」
- 门店简称，如「五星路店」
- 门店编码
- 助记码：名称每个字的拼音首字母，并且是大写。例如「五星路店」的助记码是 `WXLD`

用户只说了一个短名时，把短名原样放进 `keyword`，不要先改写成全称。

用户给的是一串大写字母或小写字母（如 `AMXL`、`amxl`）时，把它当作助记码，小写转成大写后传给 `keyword`。不要把字母展开成中文名称。

用户一次说了多家门店时，每个名称单独调用一次。不要把两个名称拼进同一个 `keyword`。

## 调用流程

1. 从用户话里抽出门店名称、简称、编码或助记码，作为 `keyword`
2. 调用 `get_shop_available_info`
3. 看 `status`、`data`、`page_info`
4. 后续要查零售时，记下选定那条的「门店编码」和「租户ID」
5. 命中多家、且无法唯一对应时，列出「门店简称」「门店编码」「门店类型」，请用户选一条。不要自己挑一个继续查零售

`page_info.pages` 大于 `page_info.current` 时，还有下一页。用户要完整清单就增大 `current` 继续查，`size` 仍为 `10`。只是定位一家门店时，先在当前页里找最匹配的一条；当前页没有、且后面还有页，再用相同 `keyword` 把 `current` 加 1。

## 返回结构

成功：`status` 为 `success`。列表在 `data`，分页在 `page_info`（`current` / `size` / `pages` / `total`）。

无数据：`status` 为 `error`，`message` 为「未找到可用门店信息」。这表示当前关键词没有命中正常门店，换一个名称、简称或编码再查。

未授权：`message` 为「未授权」。直接告诉用户未授权，不要换关键词、翻页或改参数再试。

`data` 每条记录包含下面全部字段，顺序与 `shop_info_data_process` 的输出一致：

| 字段 | 用途 |
| --- | --- |
| `租户ID` | 传给门店零售或商品零售的 `tenant_id` |
| `企业ID` | 企业标识，用来判断该门店是否属于同一家企业 |
| `机构ID` | 机构标识，是门店或企业的唯一标识，用来判断门店或企业的唯一性，如果两个门店编码相同，机构ID不同，说明是两家门店 |
| `门店编码` | 传给门店零售或商品零售的 `store_code`。类型在零售工具里是字符串列表 |
| `门店名称` | 展示 |
| `门店简称` | 展示。用户口头说的短名通常对这个字段 |
| `助记码` | 核对 |
| `门店类型` | 已转成「直营」或「加盟」 |
| `门店状态` | 本工具结果为「正常」 |
| `区域ID` | 区域标识 |
| `区域编码` | 展示或核对 |
| `区域名称` | 展示 |
| `座机号码` | 仅用户问电话时展示 |
| `门店地址` | 仅用户问地址时展示 |
| `国家定点医保机构码` | 仅用户问医保时展示 |
| `就医地医保区划码` | 仅用户问医保时展示 |
| `定点医保机构名称` | 仅用户问医保时展示 |

只问门店信息时，默认展示「门店编码」「门店简称」「门店类型」「区域名称」「门店状态」。

用户要按区域查零售时，不要用这里的「区域ID」直接查零售。先读 `/skills/erp-shop-retail/region.md`，用区域树收集该区域和正常下级的 ID。门店结果里的「区域名称」只用于展示和核对。

## 示例

用户：「五星路店是哪家」

```
get_shop_available_info(keyword="五星路店")
```

用户给了门店编码 `1001`：

```
get_shop_available_info(keyword="1001")
```

用户：「查一下 AMXL 的门店」

```
get_shop_available_info(keyword="AMXL")
```

用户要五星路店和人民路店的编码，调用两次：

```
get_shop_available_info(keyword="五星路店")
get_shop_available_info(keyword="人民路店")
```
